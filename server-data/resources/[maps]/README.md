# `[maps]`

Drop zone for imported **maps / MLOs** (interiors, custom locations).

Provided later via asset import; not stored in Git (only this README + `.keep`
are tracked). See [`docs/ASSET_IMPORT.md`](../../../docs/ASSET_IMPORT.md).

Gun store locations currently use configurable **world coordinates**
(`flrp_gunstores/shared/config.lua`) and do not require an MLO. Once map assets
land, update store coordinates to match the new interiors.
